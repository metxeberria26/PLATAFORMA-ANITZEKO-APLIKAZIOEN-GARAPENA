1Arazoa

RPG joko bat programatzen ari zara. Zure taldeak 5 pertsonaia ditu, eta bakoitzaren bizitza gorde behar duzu. Orain arte ikasitakoarekin, honela egingo zenuke:

int bizitza1 = 80;
int bizitza2 = 45;
int bizitza3 = 0;
int bizitza4 = 120;
int bizitza5 = 30;

int batura = bizitza1 + bizitza2 + bizitza3 + bizitza4 + bizitza5;
Pentsatu une batez

Eta taldeak 50 pertsonaia baditu? Eta jokalariak berak erabakitzen badu zenbat izango diren? Ezin dituzu aldagaiak "begizta batean sortu", eta ezin duzu bizitzaI idatzi i aldatuz joateko.

Behar duguna da aldagai bakar bat, balio asko gordetzen dituena, eta posizio-zenbaki batez atzitzeko modukoa. Horixe da array bat.

2Zer da array bat?

Array bat mota bereko elementuen multzo ordenatua da, tamaina finkoa duena, eta elementu bakoitza indize baten bidez atzitzen da. Ingelesezko array hitzak "lerrokadura, multzo ordenatua" esan nahi du. Gaztelaniazko dokumentazioan matriz edo arreglo ere deitzen zaio.

Irudikatu armairutxo zenbakidun ilara bat bezala (gimnasioetako taquillak). Armairutxo guztiak berdinak dira (mota bera), kopurua eraikitzean erabakitzen da (tamaina finkoa), eta bakoitzak bere zenbakia du (indizea).

Lapurra

5 elementu → indizeak 0tik 4ra.

Hiru arau, beti
  1. Mota bera: int[] batean int-ak bakarrik gorde daitezke.
  2. Tamaina finkoa: sortu ondoren ezin da handitu edo txikitu.
  3. Indizea 0tik hasten da: lehena [0] da, eta azkena [Length - 1].

Zergatik hasten da 0tik? (barrutik nola dabilen)

Array bat sortzean, .NET-eko exekuzio-inguruneak (CLR) memoria-bloke jarraitu bat erreserbatzen du. int bakoitzak 4 byte hartzen ditu, eta elementuak bata bestearen ondoan daude:

helbidea1000[0]
helbidea1004[1]
helbidea1008[2]
helbidea1012[3]
helbidea1016[4]

Elementu baten helbidea kalkulatzeko: hasiera + indizea × 4. Indizeak ez du esaten "zenbagarrena den", baizik eta hasieratik zenbat posizio salto egin behar diren. Lehena hasieran bertan dago (0 salto), eta horregatik da [0]. Kalkulu hau oso azkarra da: array batean edozein posizio atzitzeak denbora bera behar du, 0 izan zein 1.000.000 izan.

3Array bat sortzea

Hiru modu daude. Hirurek gauza bera egiten dute: mota, izena eta tamaina finkatu.

int[] bizitza = new int[5];

// B) Balioak zuzenean: tamaina balio kopuruak erabakitzen du (5)
int[] bizitza2 = { 80, 45, 0, 120, 30 };

// C) Gauza bera, luzeago idatzita
int[] bizitza3 = new int[] { 80, 45, 0, 120, 30 };

// Beste mota batzuk ere bai:

double[] prezioak = new double[10];

Noiz erabili bakoitza?

A) balioak programa exekutatzean ezagutuko dituzunean (adibidez, erabiltzaileari eskatuko dizkiozunean). B) balioak aldez aurretik ezagutzen dituzunean. C) B-ren berdina da; dokumentazioan ikusiko duzu, baina B laburragoa da.

Zer dauka bool[] atea = new bool[3]; egin ondoren?

  1. Ezer ez, errore bat ematen du
  2. { true, true, true }
  3. { false, false, false }
  4. { null, null, null }
Erantzuna ikusi

c) new-ek elementu guztiak motaren balio lehenetsiarekin betetzen ditu. bool-en kasuan, false.

4Irakurri, idatzi eta Length

int[] bizitza = { 80, 45, 0, 120, 30 };

int x = bizitza[3];          // IRAKURRI: x = 120
bizitza[2] = 50;             // IDATZI: Arkulariak 50 bizitza ditu orain
bizitza[1] = bizitza[1] + 10;   // irakurri, kalkulatu eta idatzi: 55

Console.WriteLine(bizitza.Length);   // 5 (elementu kopurua)
int azkena = bizitza[bizitza.Length - 1];   // 30 (azken elementua)

Length arrayaren propietate bat da: zenbat elementu dituen esaten du. Ez da metodo bat (ez du parentesirik), eta ezin da aldatu.

🔍 Armairutxo-esploratzailea

Idatzi indize bat eta probatu. Zer gertatzen da 5, 7 edo -1 idazten baduzu?

IndexOutOfRangeException

Existitzen ez den posizio bat atzitzen baduzu (bizitza[5] edo bizitza[-1]), programa exekuzioan geldituko da errore honekin: Index was outside the bounds of the array. Konpilatzaileak ez du abisatzen; programa exekutatzean gertatzen da. Errore hau arrayekin ohikoena da, eta normalean <= bat dago < baten ordez.

string[] inb = { "ezpata", "edabea", "giltza", "mapa" };
Zer inprimatzen du Console.WriteLine(inb[inb.Length - 2]);?

  1. edabea
  2. giltza
  3. mapa
  4. IndexOutOfRangeException
Erantzuna ikusi

b) Length 4 da, beraz inb[4 - 2] = inb[2] = "giltza".

5for batekin zeharkatzea

Hemen dago arrayen benetako indarra. Indizea zenbaki bat denez, aldagai bat erabil dezakegu indize gisa, eta begizta batekin elementu guztiak bisitatu. i aldagaia armairutxoz armairutxo mugitzen den hatza da.

int[] bizitza = { 80, 45, 0, 120, 30 };
int batura = 0;
for (int i = 0; i < bizitza.Length; i++)
{
    batura = batura + bizitza[i];
}
Console.WriteLine(batura);   // 275
Begizta "kanonikoa"

for (int i = 0; i < izena.Length; i++) → i 0tik hasten da eta Length - 1-en amaitzen da. Beti <, inoiz ez <=. Erabili Length, ez 5 idatzita: horrela, arrayaren tamaina aldatzen bada, kodeak berdin funtzionatuko du.

Zer gertatzen da kode honekin?

int[] z = { 4, 8, 15 };
for (int i = 0; i <= z.Length; i++)
{
    Console.WriteLine(z[i]);
}
  1. 4, 8, 15 inprimatzen ditu
  2. 8 eta 15 bakarrik inprimatzen ditu
  3. Ez da konpilatzen
  4. 4, 8, 15 inprimatzen ditu eta gero IndexOutOfRangeException
Erantzuna ikusi

d) <= erabiltzean, i 3ra iristen da, eta z[3] ez da existitzen (0, 1, 2 bakarrik). Konpilatu egiten da; errorea exekuzioan agertzen da.

6foreach eta for: noiz bata, noiz bestea

foreach ikusi duzu dagoeneko string-ak zeharkatzeko. Arrayekin ere badabil: "elementu bakoitzeko, egin hau".

foreach (int b in bizitza)
{
    Console.WriteLine(b);   // b-k elementuaren BALIOA du, ez indizea
}
forforeach
Indizea eskuragarriBai (i)Ez
Arrayko balioak aldatuBai (z[i] = ...)Ez (irakurtzeko soilik)
Zati bat bakarrik zeharkatuBaiEz, beti osorik
Akatsak egiteko arriskuaHandiagoa (<=, mugak)Txikiagoa
Noiz erabiliPosizioa behar denean edo aldatu behar deneanElementu guztiak irakurri besterik ez denean

Industrian bi forma erabiltzen dira. foreach nahiago izaten da indizea behar ez denean, irakurterrazagoa delako. Zalantza baduzu, for-ak beti funtzionatzen du.

7Patroi klasikoak

Arrayekin egiten diren ariketa gehienak lau patroiren aldaerak dira. Ikasi ideia, ez kodea buruz.

PatroiaIdeiaTranpa
Metatzailea (batura)Aldagai bat 0tik hasi, eta elementu bakoitza gehitu.Aldagaia begiztatik kanpo sortu behar da.
KontagailuaAldagai bat 0tik hasi, eta baldintza betetzen den bakoitzean ++.Kontatu behar dena ez da balioa, baizik eta zenbat aldiz betetzen den.

    if (b > 50)

        kopurua++;
    }
}
Console.WriteLine($"{kopurua} pertsonaia sendo");

8Arrayak eta metodoak

Funtzioetan ikusi zenuen bezala, metodo batek parametroak jaso eta balio bat itzul dezake. Array bat parametro gisa pasa daiteke, eta array bat ere itzul daiteke:

// Array bat JASO eta zenbaki bat ITZULI
static int Batura(int[] zenbakiak)
{
    int batura = 0;
    for (int i = 0; i < zenbakiak.Length; i++)
    {
        batura = batura + zenbakiak[i];
    }
    return batura;
}

// Array bat JASO eta array BERRI bat ITZULI
static int[] Bikoiztu(int[] zenbakiak)
{
    int[] berria = new int[zenbakiak.Length];   // tamaina bereko array berria
    for (int i = 0; i < zenbakiak.Length; i++)
    {
        berria[i] = zenbakiak[i] * 2;
    }
    return berria;
}

// Main-etik deitzea:
int[] urrea = { 10, 25, 5 };
Console.WriteLine(Batura(urrea));        // 40
int[] bikoitza = Bikoiztu(urrea);        // { 20, 50, 10 }
Zergatik static?

Main static denez, hortik zuzenean deitzen diren metodoek ere static izan behar dute. Objektuei buruzko programazioa (POO) ikastean ulertuko duzu zergatik. Oraingoz: beti static.

Parametroaren izenak (zenbakiak) ez du zertan deitzean erabilitako aldagaiaren izen bera izan (urrea). Metodoak berdin funtzionatzen du edozein int[]-rekin: hori da metodoen abantaila.

10Autoebaluazioa

Erantzun galdera hauek praktikara pasatu aurretik. Lehen saiakeran asmatutakoak bakarrik zenbatzen dira. Ez du notarik: zuretzat da.

1. Zenbat elementu ditu int[] a = new int[8]; arrayak, eta zein da azken indizea?

  1. 7 elementu, azkena [7]
  2. 8 elementu, azkena [8]
  3. 8 elementu, azkena [7]
  4. 9 elementu, azkena [8]
Erantzuna ikusi

c) 8 elementu, 0tik 7ra indizeatuta.

2. Zer inprimatzen du?

int[] a = { 3, 6, 9 };
a[1] = a[0] + a[2];
Console.WriteLine(a[1]);
  1. 12
  2. 6
  3. 9
  4. 15
Erantzuna ikusi

a) a[0] + a[2] = 3 + 9 = 12, eta a[1]-en gordetzen da.

3. Zein lerrok ez du konpilatzen?

  1. int[] a = new int[3];
  2. int[] a = { 1, "bi", 3 };
  3. string[] s = { "a", "b" };
  4. double[] d = { 1.5, 2 };
Erantzuna ikusi

b) Array bateko elementu guztiak mota berekoak izan behar dira. d) konpilatu egiten da: 2 zenbaki osoa double bihurtzen da modu inplizituan.

4. Zer inprimatzen du?

int[] a = { 5, 1, 4 };
int k = 0;
foreach (int x in a)
{
    if (x > 2) k++;
}
Console.WriteLine(k);
  1. 0
  2. 1
  3. 9
  4. 2
Erantzuna ikusi

d) Kontagailu patroia da: 5 eta 4 dira 2 baino handiagoak.

5. Arrayko balio guztiak bikoiztu nahi dituzu (arraya bera aldatuz). Zein erabili?

  1. foreach, x = x * 2; eginez
  2. Bietako edozein
  3. for, a[i] = a[i] * 2; eginez
  4. Ezin da egin, arrayak tamaina finkoa du
Erantzuna ikusi

c) foreach-eko aldagaia irakurtzeko soilik da; balioa aldatzeko indizea behar da. Tamaina finkoa izateak ez du eragozten balioak aldatzea, elementu kopurua aldatzea baizik.

6. Zer inprimatzen du?

int[] a = { 2, 4, 6, 8 };
for (int i = a.Length - 1; i >= 0; i = i - 2)
{
    Console.Write(a[i] + " ");
}
  1. 8 4
  2. 8 6 4 2
  3. 6 2
  4. IndexOutOfRangeException
Erantzuna ikusi

a) i 3tik hasten da (8), gero 1 (4), gero -1 → baldintza false, irten.

7. Funtzio honek balio handiena itzuli behar du. Zein sarrerarekin huts egiten du?

static int Max(int[] z)
{
    int max = 0;
    foreach (int x in z)
    {
        if (x > max) max = x;
    }
    return max;
}
  1. { 3, 9, 1 }
  2. { -4, -2, -7 }
  3. { 0, 5 }
  4. Beti ondo dabil
Erantzuna ikusi

b) 0 itzultzen du, eta zuzena -2 da. Hasieran max = z[0] jarri behar da.

8. string[] s = new string[3]; egin ondoren, zer gertatzen da Console.WriteLine(s[0].Length); exekutatzean?

  1. 0 inprimatzen du
  2. 3 inprimatzen du
  3. IndexOutOfRangeException
  4. Errorea: s[0] null da eta ez du Length-ik
Erantzuna ikusi

d) string-en balio lehenetsia null da: "ez dago testurik". null baten Length eskatzeak NullReferenceException ematen du.

11Praktika: Visual Studio

Orain programatzeko txanda da. Moodleko zereginean hasierako proiektua duzu (.zip). Bertan, Program.cs fitxategiak metodo hutsak eta proba automatikoak ditu.

  1. Deskargatu eta deskonprimatu zip-a. Ireki .csproj fitxategia Visual Studiorekin (klik bikoitza).
  2. Sakatu F5. Proba guztiak [ -- ] egoeran agertuko dira: egin gabe.
  3. Bete metodoak ordenan. Bakoitzean, ezabatu throw new NotImplementedException(); lerroa eta idatzi zure kodea.
  4. Sakatu F5 berriro. Probak berde jartzen direnean, hurrengo metodora pasa.
  5. Egin 10. ariketa (ZureTaldea) eta, nahi baduzu, erronka.
  6. Igo Program.cs bakarrik Moodleko zereginera.

Hau ikusiko duzu kontsolan:

1. Batura
  [ OK ] Batura({10, 25, 5})
  [ OK ] Batura({7})
...
3. Maximoa
  [ OK ] Maximoa({40, 95, 12})
  [ X  ] Maximoa({-5, -2, -9}) negatiboak  ->  espero zen: -2  |  zurea: 0
...
4. ZenbatBizirik
  [ -- ] ZenbatBizirik({30, 0, 12, 0})  (egin gabe)
Proba batek huts egiten badu

Ez aldatu kodea zoriz. Irakurri mezua (espero zena vs zurea), jarri eten-puntu bat (F9) zure metodoan, eta jarraitu F10-ekin, aldagaiak nola aldatzen diren ikusiz. Horixe da programatzaile batek egiten duena.

12Galdera ohikoak

Array bat handitu daiteke sortu ondoren?
Ez. Tamaina aldagarria behar baduzu, List<int> erabiliko dugu (laster ikusiko dugu).

string bat char-en array bat al da?
Antzekoa da: testua[0] eta testua.Length erabil ditzakezu. Baina string-ak ezin dira aldatu (immutable): testua[0] = 'A'; ez da konpilatzen.

Zergatik ez du konpilatzaileak z[10] errorea antzematen?
Konpilatzean, askotan ez dago jakiterik arrayak zenbat elementu izango dituen edo zer balio izango duen indizeak (adibidez, erabiltzaileak idazten badu). Horregatik egiaztatzen da exekuzioan.

Eta array batek beste array batzuk izan ditzake (taula bat)?
Bai: int[,] bi dimentsiotako arrayak dira (errenkadak eta zutabeak). Hurrengo urratsa izango da.

Zer da throw new NotImplementedException(); praktikako fitxategian?
"Hau oraindik ez dago programatuta" esateko modu estandarra da. Probek detektatzen dute eta [ -- ] erakusten dute. Salbuespenak (exceptions) aurrerago ikasiko ditugu.
